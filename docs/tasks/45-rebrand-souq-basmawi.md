# 45: تغيير الاسم الظاهر إلى "سوق بسماوي" (Souq Basmawi) + شعار مؤقت ✅

> قرار المالك 2026-11-24. **ما يراه المستخدم فقط**؛ لا تغيير للمعرّفات الداخلية.

**الهدف:** الاسم الظاهر بكل التطبيقات "سوق بسماوي" (اللاتيني: Souq Basmawi)؛ السائق "سوق بسماوي - السائق"؛ اللوحة "لوحة سوق بسماوي".
**النموذج:** Sonnet. **على dev:** لا شيء (لا migration ولا نشر Edge Function ولا EAS؛ عناوين الإشعارات تأتي من صفوف قاعدة البيانات ولا تحمل اسم التطبيق، والاحتياطي عند غياب العنوان بـ `sw.js` فقط).

## ما تغيّر
- أسماء العرض: `app.config.ts` (زبون، سائق)، manifests الـ PWA الثلاثة، `postexport-web.mjs` (عنوان الصفحة ووسم iOS)، `layout.tsx`/`manifest.ts` للوحة، عناوين إشعارات الاحتياط بـ `sw.js` (زبون، سائق، أدمن)، نصوص `i18n/ar.ts`، شاشات الدخول، رأس اللوحة (Sidebar)، صفحات الخصوصية والشروط وحذف الحساب، إيصال الطباعة، رسالة الرمز المؤقت، اسم رمز TOTP (`TOTP_ISSUER` = `Souq Basmawi`)، `docs/PREVIEW.md` و`README.md` وأسماء التطبيقات بـ SPEC-driver/webpush/admin-push.
- الاختبارات والفحص الدخاني الحي (`live-smoke.spec.ts`) حُدِّثت للاسم الجديد.
- **الشعار المؤقت:** مصدره مجلد واحد `branding/` (SVG بنص محوَّل لمسارات بـ HarfBuzz وخط Cairo OFL، فلا اعتماد على خط). `pnpm brand:icons` يولّد: أيقونات PWA (192/512/maskable/apple-touch) وfavicon وأيقونة Android التكيّفية (foreground/background/monochrome) وأيقونة التطبيق والـ splash، ولوحة `icon.svg`. لاستبداله بشعار حقيقي: بدّل ملفات `branding/logo-*.svg` وشغّل الأمر.

## لم يتغيّر عمداً (معرّفات داخلية)
`com.mukhdar.*`، `slug`/`scheme`، مشروع EAS وFirebase، أسماء الحزم `@mukhdar/*`، أسماء المستودع والمجلدات ومشاريع Cloudflare والروابط، قاعدة البيانات (`mukhdar-dev`)، موضوع ntfy، وملفات SPEC/ADR/migrations التاريخية (تحتفظ باسمها وقت الكتابة). **افتراض:** اسم رمز TOTP للحسابات المسجَّلة سابقاً يبقى كما سُجّل (تسمية فقط).
