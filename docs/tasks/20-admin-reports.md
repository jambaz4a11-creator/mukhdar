# 20: التقارير

**الهدف:** SPEC-admin §2.5.

## الخطوات
- اختيار المدى، بطاقات المؤشرات من `daily_stats`، رسم يومي.
- أكثر المنتجات مبيعاً وأداء السائقين: دالتا SQL جديدتان (migration) `report_top_products(from, to, limit)` و`report_drivers(from, to)`، أدمن فقط، بتوقيت بغداد.
- متوسط التقييم وآخر 20 تعليقاً.
- تصدير CSV.

## القبول
- أرقام التقرير على بيانات seed تطابق استعلامات التحقق اليدوية.
- صفحة التقارير لمدى شهر تفتح < 1 ثانية على بيانات seed.

## الاختبارات
- pgTAP للدالتين (أرقام ومنع غير الأدمن).
- Playwright: تغيير المدى يحدّث البطاقات؛ التصدير ينزل ملفاً.
