# 19: العناوين والموظفون والإعدادات

**الهدف:** SPEC-admin §2.4 و§2.6 و§2.7.

## الخطوات
- شجرة العناوين مع إضافة بنايات بالجملة (مدى أو قائمة، معاينة، تجاهل المكرر بـ `on conflict do nothing`).
- الموظفون: قائمة غير الزبائن، بحث بالهاتف، تغيير الدور والتفعيل (`set_user_role`).
- الإعدادات: أجرة التوصيل، الحد الأدنى، فتح/غلق المتجر ورسالته، مؤشر الإشعارات العالقة.

## القبول
- إضافة 1..650 بناية لقسم فرعي بعملية واحدة.
- إغلاق المتجر يظهر الشريط بتطبيق الزبون ويمنع الطلب.

## الاختبارات
- وحدة: تحليل المدى والقوائم ("1-650"، "1,2,5-9"، مدخلات خاطئة).
- Playwright: ترقية رقم لسائق؛ محاولة الأدمن تخفيض نفسه تظهر رسالة.
