# 18: المنتجات والمخزون

**الهدف:** SPEC-admin §2.2 و§2.3.

## الخطوات
- الأقسام: CRUD، تعطيل، ترتيب بالسحب.
- المنتجات: جدول بالأعمدة المحددة (مع `product_costs` و`stock`)، نموذج إنشاء/تعديل، تعديل سريع للسعر، تعطيل.
- رفع الصور: تصغير بالمتصفح (canvas ← WebP 800px، < 200KB) ثم Storage `product-images/<product_id>/<timestamp>.webp`.
- المخزون: جدول الأرصدة، أزرار الحركات (`adjust_stock`)، سجل الحركات بصفحات.
- تنبيه منتجات بلا سعر شراء.

## القبول
- صورة 5MB من الهاتف تُرفع بحجم < 200KB.
- سعر 1100 مرفوض بالنموذج وبقاعدة البيانات.

## الاختبارات
- Playwright: إنشاء منتج بصورة، تعطيله يخفيه من تطبيق الزبون (استعلام anon)، إضافة مشتريات تجعله `in_stock`.
- وحدة: تصغير الصورة، التحقق من السعر.
