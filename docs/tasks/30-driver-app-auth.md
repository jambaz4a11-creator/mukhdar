## القبول
- التسجيل لا ينشئ أي حساب؛ السر محفوظ بـ SecureStore قبل الإرسال ولا يظهر بأي log.
- مسار كامل على dev (Expo Go/محاكي Android): تسجيل ← موافقة من اللوحة أو SQL الاختبار ← الشاشة تتحول خلال 30 ثانية ← اختيار الرمز ← تبويبات.
- جهاز/تثبيت آخر بنفس الرقم لا يقدر يختار الرمز.
- طلب مرفوض ← رسالة "ما انقبل طلبك" و"طلب جديد".
- سائق رمزه مؤقت ← شاشة التغيير بلا تخطٍ؛ زبون يدخل بتطبيق السائق ← "غير مفعّل كسائق".
- كل نص عربي من `i18n`، وكل خطأ خادم عبر `errors.ts`.
