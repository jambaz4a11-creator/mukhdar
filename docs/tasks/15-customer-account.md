# 15: حسابي وحذف الحساب

**الهدف:** SPEC-customer §2.9.

## الخطوات
- تعديل الاسم (`update profiles set full_name`)، **تغيير رمز الدخول (PIN)**، عناويني، روابط الخصوصية والشروط، تواصل معنا، الخروج.
- تغيير الـ PIN (ADR 0001): الرمز الحالي (يُتحقق منه بـ `signInWithPassword` بنفس الرقم) ثم الجديد مرتين ← `validatePin(new, phone)` ← `supabase.auth.updateUser({ password: normalizePin(new) })`. بعد النجاح رسالة "تم تغيير الرمز" (مفيد بعد إعادة الضبط من الأدمن).
- حذف الحساب: تأكيد مزدوج ← `delete-account` ← خروج وتفريغ البيانات المحلية.
- صفحات الخصوصية والشروط (نص أولي يُراجع من صاحب المشروع) في لوحة الأدمن كصفحات عامة.

## القبول
- مسار حذف الحساب يعمل كاملاً على جهاز حقيقي وواضح لمراجع Apple (أقل من 3 ضغطات من "حسابي").

## الاختبارات
- RNTL: تغيير الـ PIN (رمز حالي خاطئ ← رسالة، رمز جديد سهل ← رفض، نجاح يستدعي `updateUser` بأرقام لاتينية)؛ رسالة `ACTIVE_ORDER`؛ نجاح الحذف يفرغ التخزين ويرجع للرئيسية.

## الحالة (2026-11-15)
- ✅ حسابي (تصميم Account): بطاقة الاسم (أول حرف، الاسم أو "بدون اسم"، الهاتف) وزر "تعديل الاسم" ← `account/name` (2..80 حرفاً بعد تنظيف المسافات، `update profiles set full_name`)؛ القائمة: عناويني (العدد، T12)، طلباتي، تواصل معنا (واتساب، `EXPO_PUBLIC_SHOP_WHATSAPP`)، اتصل بالمحل (`tel:`، `EXPO_PUBLIC_SHOP_PHONE` جديد)، تغيير رمز الدخول، سياسة الخصوصية والشروط (`EXPO_PUBLIC_PRIVACY_URL`/`EXPO_PUBLIC_TERMS_URL`، https فقط). كل رابط خارجي **مخفي حتى يُضبط** بقيمة صالحة. ثم تسجيل الخروج وحذف الحساب ونص "حذف الحساب نهائي…".
- ✅ تغيير الـ PIN (`account/pin`، ADR 0001): الجديد مرتين ← `validatePin(new, phone)` (يُرفض قبل أي طلب) ← الحالي بـ `signInWithPassword` بنفس الرقم ← `updateUser({ password })` بأرقام لاتينية ← "تم تغيير الرمز". الحالي الخاطئ ← "الرمز الحالي غير صحيح"؛ نفس الرمز ← رفض.
- ✅ حذف الحساب: الزر **مباشرة بحسابي** (ضغطة) ← تأكيد أول ("متابعة") ← تأكيد نهائي ("احذف حسابي نهائياً") ← `delete-account` (POST). `ACTIVE_ORDER` وغيره برسالة عربية عبر `parseFunctionError` (الجلسة والبيانات تبقى). النجاح ← تفريغ السلة ومفتاح الطلب والعنوان المختار والكاش (ذاكرة وAsyncStorage) ورمز الإشعارات المحلي ← `signOut({ scope: 'local' })` ← الرئيسية + "تم حذف حسابك".
- ✅ الاسم لا يُحفظ على الجهاز (مثل العناوين والطلبات).
- ✅ اختبارات (`account.test.tsx`، 15): روابط واتساب/اتصال/https (القيمة الوهمية و`http`/`javascript:` مرفوضة)، الشاشة (الاسم والهاتف، الروابط مخفية بلا إعداد وتفتح الصحيح مع الإعداد، التنقل)، الحذف (تأكيدان والتراجع، `ACTIVE_ORDER`، النجاح يفرّغ التخزين ويرجع للرئيسية، انقطاع الشبكة)، تغيير الـ PIN (حالي خاطئ، سهل، عدم التطابق، نجاح بأرقام لاتينية من مدخلات عربية-هندية، نفس الرمز)، تعديل الاسم. المجموع 161 اختباراً.
- ⏳ صفحات الخصوصية والشروط نفسها بلوحة الأدمن (T16)؛ الروابط تُضبط بعدها.
- ⏳ يدوي لدى صاحب المشروع: مسار الحذف كاملاً على جهاز حقيقي (حساب تجريبي على `mukhdar-dev`).
