# 15: حسابي وحذف الحساب

**الهدف:** SPEC-customer §2.9.

## الخطوات
- تعديل الاسم (`update profiles set full_name`)، **تغيير رمز الدخول (PIN)**، عناويني، روابط الخصوصية والشروط، تواصل معنا، الخروج.
- تغيير الـ PIN (ADR 0001): الرمز الحالي (يُتحقق منه بـ `signInWithPassword` بنفس الرقم) ثم الجديد مرتين ← `validatePin(new, phone)` ← `supabase.auth.updateUser({ password: normalizePin(new) })`. بعد النجاح رسالة "تم تغيير الرمز" (مفيد بعد إعادة الضبط من الأدمن).
- حذف الحساب: تأكيد مزدوج ← `delete-account` ← خروج وتفريغ البيانات المحلية.
- صفحات الخصوصية والشروط (نص أولي يُراجع من صاحب المشروع) في لوحة الأدمن كصفحات عامة.

## القبول
- مسار حذف الحساب يعمل كاملاً على جهاز حقيقي وواضح لمراجع Apple (أقل من 3 ضغطات من "حسابي").

## الاختبارات
- RNTL: تغيير الـ PIN (رمز حالي خاطئ ← رسالة، رمز جديد سهل ← رفض، نجاح يستدعي `updateUser` بأرقام لاتينية)؛ رسالة `ACTIVE_ORDER`؛ نجاح الحذف يفرغ التخزين ويرجع للرئيسية.
