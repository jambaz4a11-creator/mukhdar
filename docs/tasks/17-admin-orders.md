# 17: صفحة الطلبات

**الهدف:** SPEC-admin §2.1.

## الخطوات
- تبويبات الحالات مع عدادات (استعلام `count` بالحالة، `head: true`).
- جدول بصفحات 50 (keyset)، فلاتر، بحث برقم الطلب أو الهاتف.
- Realtime على `INSERT` مع صوت، و`UPDATE` للمعروض.
- جدول الطلبات مكوّن واحد قابل لإعادة الاستخدام (فلتر جاهز "اليوم" للرئيسية بـ T25).
- لوحة التفاصيل: الزبون (الاسم، الهاتف)، العنوان الكامل (`formatAddress`) وملاحظته، ملاحظة الطلب، بنود، سجل الحالات، التقييم، أزرار حسب الدور (`set_order_status` ومنها "جاهز" ← `ready`، `assign_driver` من `preparing`/`ready`)، تكلفة وربح للأدمن.
- صفحة طباعة 80mm.

## القبول
- طلب من تطبيق الزبون يظهر باللوحة خلال ثانيتين بصوت تنبيه.
- الموظف لا يرى أعمدة التكلفة (لا تُجلب أصلاً).

## الاختبارات
- Playwright: بدء تحضير، تعيين سائق، إلغاء بسبب، فلترة، بحث، طباعة تفتح.
- وحدة: أزرار الإجراءات الصحيحة لكل (حالة × دور)؛ عرض العنوان الكامل والهاتف بلوحة التفاصيل.
