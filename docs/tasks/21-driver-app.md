# 21: تطبيق السائق

> **أُلغيت، حلّت محلها T27–T33** (قرار المالك 2026-11-19: المطوّر الخارجي أُلغي، وتطبيق السائق `apps/driver` يُبنى داخل هذا الـ repo حسب [SPEC-driver](../SPEC-driver.md)). المحتوى أدناه تاريخي فقط؛ الخطة الحالية بجدول [00-README](00-README.md).

**الهدف:** SPEC-driver كاملاً.

## الخطوات
- `apps/driver` بنفس هيكل المهمة 09 (اسم، أيقونة، bundle id مختلف).
- الدخول (إعادة استخدام مكونات المهمة 10 عبر `packages/ui` إن لزم) + حارس الدور.
- الطلبات المتاحة، طلباتي الحالية (Realtime)، التفاصيل وأزرار الحالة، السجل وملخص اليوم.
- الإشعارات: إذن مبكر، قناة Android عالية الأولوية.

## القبول
- دورة كاملة على أجهزة حقيقية: زبون يطلب (إشعار للأدمن فقط) ← الأدمن يحضّر ثم "جاهز" (`ready`) ← سائقان يستلمان إشعاراً ← أحدهما يقبل ← السائق يستلم ويوصل ← الزبون يقيّم.

## الاختبارات
- RNTL: لا هاتف بالبطاقة قبل القبول؛ الأزرار لكل حالة؛ رسالة "أخذه سائق آخر".
- تكامل: قبول متزامن (واحد ينجح).
