# 21: تطبيق السائق

**الهدف:** SPEC-driver كاملاً.

## الخطوات
- `apps/driver` بنفس هيكل المهمة 09 (اسم، أيقونة، bundle id مختلف).
- الدخول (إعادة استخدام مكونات المهمة 10 عبر `packages/ui` إن لزم) + حارس الدور.
- الطلبات المتاحة، طلباتي الحالية (Realtime)، التفاصيل وأزرار الحالة، السجل وملخص اليوم.
- الإشعارات: إذن مبكر، قناة Android عالية الأولوية.

## القبول
- دورة كاملة على أجهزة حقيقية: زبون يطلب ← سائقان يستلمان إشعاراً ← أحدهما يقبل ← الأدمن يحضّر ← السائق يوصل ← الزبون يقيّم.

## الاختبارات
- RNTL: لا هاتف بالبطاقة قبل القبول؛ الأزرار لكل حالة؛ رسالة "أخذه سائق آخر".
- تكامل: قبول متزامن (واحد ينجح).
