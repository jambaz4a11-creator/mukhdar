# 12: العناوين

**الهدف:** SPEC-customer §2.5.

## الخطوات
- شاشة اختيار متسلسل: قطاع (A، B) ← وحدة (A1..A9 / B1..B8) ← عمارة 1..100 (بحث بالرقم + `FlashList`) ← الشقة والملاحظة والتسمية.
- CRUD على `addresses` مباشرة (RLS يحصرها بصاحبها). عنوان افتراضي واحد (تحديث البقية عند التعيين).
- تخزين القوائم الهرمية ليوم واحد.

## القبول
- اختيار عمارة (100 لكل وحدة) بالبحث بأقل من ثانية. التسميات: "الوحدة"، "العمارة".

## الاختبارات
- RNTL: لا يُحفظ بدون شقة؛ تغيير القطاع يمسح الاختيارات التالية.
- تكامل: زبون لا يقرأ عناوين زبون آخر (مغطى بالمهمة 03، يُعاد هنا كاختبار API سريع).
