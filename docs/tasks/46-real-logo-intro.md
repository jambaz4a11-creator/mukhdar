# 46: الشعار الحقيقي + مقدمة التطبيق ✅

> قرار المالك 2026-11-24. بلا cloud ولا migration ولا إعادة بناء APK (الأيقونة الجديدة بتطبيق الموبايل تظهر عند البناء القادم؛ الـ PWA تتحدّث بالنشر).
**النموذج:** Sonnet. **على dev:** لا شيء.

## ما تغيّر
- **الشعار:** مصدره `branding/logo.png` (1024، عربة خضراء بالثمار وخطوط سرعة برتقالية على `#F7F8F3`). نُسخ المصدران من `branding/source/` (الفيديو مرجع فقط، لا يُستعمل بالتطبيق).
- **الأيقونات:** `pnpm brand:icons` (`branding/build-icons.mjs`) يزيل الخلفية بمَطّ نظيف (alpha + استعادة اللون) ويولّد: الأيقونة الكبيرة والـ splash الأصلي (الشعار كاملاً بخطوط السرعة)، والأحجام الصغيرة (favicon و192 و512 و180 و`icon.svg` سابقاً ← `icon.png` للوحة) **بدون خطوط السرعة ومكبَّرة لتملأ الإطار**، وmaskable وAndroid adaptive بالمنطقة الآمنة (مقاس 1160 و1400)، وأيقونة Android أحادية (silhouette أبيض)، و`badge-96.png` (شارة إشعارات Android أبيض شفاف؛ بدّل `badge` بـ `sw.js` للتطبيقات الثلاثة بدل `icon-192`). فُحص 48px بالعين: العربة والثمار مقروءة.
- **المقدمة:** `apps/customer/src/components/IntroOverlay.tsx` (الزبون فقط، فوق التنقل بـ `_layout.tsx`). عربة وخطوط شفافة من الشعار تُحرَّك بـ `Animated` من React Native (بلا Reanimated ولا Lottie ولا فيديو؛ صفر اعتماديات جديدة، `useNativeDriver` على الموبايل): دخول سريع، كبح، ارتداد خفيف، تلاشٍ. **1.8 ث**، مرة لكل تشغيل، تخطٍّ بلمسة (زر وصول بالتسمية "تخطي المقدمة")، تُتجاوز مع `prefers-reduced-motion` (`AccessibilityInfo.isReduceMotionEnabled`، على الويب يقرأ media query)، وتُتجاوز بـ jest وPlaywright (`navigator.webdriver`) فلا تبتلع نقرات الفحوص الحية. لا تؤخر الدخول ولا شاشة الطلب: التطبيق مركَّب ويعمل تحتها والغلاف يزول بلمسة.
- الاختبارات: `intro-overlay.test.tsx` (لا تلقائية بالاختبار، تخطٍّ بلمسة، reduced-motion، المدة ≤ 2 ث وانتهاؤها وحدها).

## افتراضات
- **لا SVG:** تتبّع شعار متعدد الألوان بأداة تلقائية يشوّه الحواف (لا potrace محلياً)، فاعتُمد PNG عالي الدقة كمصدر (السماح بالبديل بالطلب)؛ الأصول المشتقة تُولَّد منه. إن وصل SVG لاحقاً يُستبدل المصدر فقط.
- الـ splash الأصلي يبقى ثابتاً (الشعار) ثم تبدأ المقدمة؛ أبسط من مقدمة داخل الـ splash الأصلي (لا يدعم تحريكاً بلا dev build).
- `theme_color` يبقى `#1F6B3A` (يطابق أخضر الشعار)، وخلفية التطبيق `#F7F8F3` تطابق خلفية الشعار تماماً.
- تطبيق السائق يأخذ الأيقونات الجديدة نفسها (مصدر واحد) بلا مقدمة.
